# Lenovo Legion 5

## Product Overview

The Lenovo Legion 5 is a performance laptop for gaming and demanding creative work, with a discrete RTX-class GPU, large storage, and a higher-power chassis.

## Key Specifications

- **Processor:** Intel Core i7 class processor
- **Memory:** 16GB RAM
- **Storage:** 1TB SSD
- **Display:** 15.6-inch display
- **Graphics:** RTX 4060 class discrete GPU
- **Weight:** 2.30 kg
- **Use Cases:** Gaming, creative work, and coding

## Compatibility

Designed for Windows gaming and GPU-assisted creative applications. Its heavier chassis favors performance over portability.

## Common Questions

**Q: Is this intended for lightweight travel?**

A: No. The product is optimized for gaming and performance; the 2.30 kg chassis is a deliberate trade-off.
